Tutorial: Quiz

Maak je eigen quiz

Welkom bij deze tutorial! We gaan samen stap voor stap een interactieve quiz bouwen en aan het eind van de tutorial heb jij je eigen quiz gemaakt die je kunt spelen met vrienden!

Setup

Voor we aan de slag kunnen, installeren we eerst Visual Studio Code en een paar extensies

Je kunt Visual Studio Code downloaden via: https://code.visualstudio.com/

Na de installatie is het handig om deze extensies te installeren:

  • Live Server (om je website direct te bekijken)
  • HTML CSS Support (voor hulp bij het schrijven van HTML en CSS)
  • ESLint (voor hulp bij het schrijven van JavaScript)

Maak vervolgens deze drie bestanden aan in Visual Studio Code:

  • index.html (Om de structuur van je quiz te bouwen)
  • main.css (Om je opmaak en stijl te definieren)
  • script.js (Om logica te schrijven en de quiz interactief te maken)
  • questions.js (Hier vul je de vragen en antwoorden in van de quiz)

Tip: Je kunt een map genaamd "quiz" aanmaken en daarin de 4 bestanden plaatsen om alles georganiseerd te houden

Stap 2: Toon de vragen

Nu gaan we de vragen voor onze quiz maken. Dit doen we door een lijst te maken in questions.js met vragen en antwoorden.

In questions.js maken we een array (een lijst) van objecten, waarbij elk object een vraag voorstelt.

Voor elke vraag willen we de volgende zaken opslaan:

  • De tekst van de vraag
  • Een lijst met mogelijke antwoorden
  • Voor elk antwoord: of het correct is of niet

Stap 3: Functionaliteit van de quiz

Nu we de vragen hebben, is het tijd om de quiz functioneel te maken. In deze stap gaan we JavaScript gebruiken om:

  • De vragen op de pagina te tonen
  • De antwoorden te controleren
  • De score bij te houden
  • Feedback te geven over welke antwoorden juist of fout waren

  1. We maken een hoofdfunctie generateQuiz die vier parameters accepteert:

3.2: De showQuestions functie maken

Nu gaan we een functie maken om de vragen op de pagina te tonen. Kopieer de volgende code en plak deze in de generateQuiz functie onder let score = 0;.

See the Pen Untitled by Leon Smits (@Leon-Smits) on CodePen.

Wat deze functie doet:

  1. We maken eerst een lege array (lijst) genaamd questionList om alle HTML voor vragen in op te slaan.
  2. Dan gebruiken we forEach om door elke vraag in onze lijst te lopen:
    • Voor elke vraag maken we een nieuwe lege lijst answers voor de antwoordopties
    • We gebruiken nog een forEach om door elk antwoord te lopen en maken daar HTML voor
    • Voor elk antwoord maken we een label met een radio button, waarbij we ook opslaan of het antwoord correct is
    • Dan voegen we alle antwoorden samen met de vraag in een div-element dat we dan aan questionList toevoegen
  3. Tenslotte zetten we nu alle gemaakt HTML in de quizContainer

3.3: De showResults functie maken

Nu maken we een functie om te controleren of de antwoorden correct zijn. Kopieer de volgende code en plak deze in de generateQuiz functie onder de showQuestions functie.

See the Pen Untitled by Leon Smits (@Leon-Smits) on CodePen.

Wat deze functie doet:

  1. We vinden alle vraag-containers op de pagina en resetten de score naar 0
  2. Dan doorlopen we elke vraag met forEach:
    • We zoeken het geselecteerde antwoord (de aangevinkte radio button)
    • We kijken of dat antwoord correct is door het data-correct attribuut te controleren
    • Als het antwoord correct is, verhogen we de score en tonen we een "JUIST!" bericht
    • Als het antwoord fout is, zoeken we het juiste antwoord en tonen dat en komt en een "FOUT" bericht
    • We maken alle radio buttons disabled zodat de gebruiker niet meer kan veranderen na het nakijken
  3. Als laatste tonen we de totale score op het scherm en verbergen de submit knop

Stap 4: Styling

Nu heb je de basis van hoe je een quiz maakt in HTML en JavaScript. Nu kun je alles stylen zoals je wilt. Dit doe je in je main.css bestand. Hierin kun je:

  • Kleuren toevoegen aan je quiz
  • De lettertypen veranderen
  • marges en padding toevoegen aan elementen
  • Effecten toevoegen zoals schaduwen of afgeronde hoeken
  • De quiz responsive maken, zodat deze er goed blijft uitzien op verschillende schermen

Enkele eenvoudige CSS-eigenschappen die je kunt gebruiken zijn:

  • color: Voor tekstkleur
  • background-color: Voor achtergrondkleur
  • font-family: Voor het lettertype
  • padding: Voor ruimte binnen een element
  • margin: Voor ruimte buiten een element
  • border-radius: Voor afgeronde hoeken
  • box-shadow: Voor schaduwen rond elementen

Deze code zorgt al voor een styling aan de quiz. Je kunt deze kopieren en in je main.css plakken, maar pas gerust dingen aan en experimenteer zelf met de verschillende CSS-eigenschappen. De mogelijkheden zijn eindeloos!!!
