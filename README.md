##  Over dit project

Deze repository bevat een **interactieve leertool** die bestaat uit twee hoofdonderdelen:

1. **Interactieve Quiz**  
   Een volledig functionele quizapplicatie gebouwd met **HTML**, **CSS** en **JavaScript**. Gebruikers beantwoorden meerkeuzevragen en ontvangen direct feedback.

2. **Stap-voor-stap Tutorial**  
   Een uitgebreide handleiding die je stap voor stap leert hoe je zelf een quiz bouwt – perfect voor beginners!

---

## Functionaliteiten van de Quiz

-  Dynamisch gegenereerde quiz vanuit een JavaScript-array  
-  Meerkeuzevragen via radio buttons  
-  Directe feedback (juist/fout + correct antwoord)  
-  Score bijhouden en weergeven op het einde  

---

## Functionaliteiten van de Tutorial

De tutorial is verdeeld over vier fasen:

1. **Setup** – Tools installeren en projectstructuur opzetten  
2. **HTML** – Basisstructuur van de quiz maken  
3. **JavaScript** – Functionaliteit toevoegen  
4. **CSS** – Styling en layout toepassen

📌 Inclusief:
- Interactieve **CodePen-voorbeelden**  
- Uitleg bij elke codesectie  
- Responsive design – werkt op zowel desktop als mobiel
